---

## 리팩토링 원칙
- 동작은 절대 바꾸지 않는다
- 한 번에 하나의 변경만
- 변경 전 테스트 실행, 변경 후 테스트 재실행

## 수행 순서
1. 대상 코드 읽기
2. 개선 가능한 항목 목록화 (우선순위 포함)
3. 사용자 승인 후 하나씩 적용
4. 각 변경 후 테스트 실행 확인

## 주요 리팩토링 패턴
- 긴 함수 → 작은 함수로 분리
- 깊은 중첩 → 조기 반환으로 평탄화
- 중복 코드 → 공통 함수 추출
- 매직 넘버/문자열 → 상수화
- 복잡한 조건식 → 명확한 변수명으로 추출
