---

## 디버깅 순서

### 1. 재현
- 오류 메시지 또는 증상 파악
- 재현 조건 확인 (항상 발생? 특정 조건?)
- 관련 로그 수집

### 2. 원인 추적
- 오류 발생 지점 파악 (스택 트레이스 역추적)
- 가설 설정 → 가설 검증 순서로 접근
- 추측으로 코드 수정 금지 — 원인 확인 후 수정

### 3. 수정
- 최소한의 변경으로 수정
- 수정 후 재현 조건으로 검증
- 유사한 패턴의 다른 버그 존재 여부 확인

### 4. 재발 방지
- 수정된 케이스에 대한 테스트 추가
- 근본 원인이 설계 문제라면 리팩토링 제안
