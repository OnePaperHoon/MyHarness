## 수행 순서

### 1. 설계 (구현 전 반드시)
- 기능 요구사항 정리
- 영향받는 파일/모듈 파악
- 인터페이스(함수 시그니처, API 스펙) 먼저 정의
- 사용자에게 설계 확인 요청

### 2. 구현
- 인터페이스부터 작성, 내부 구현은 이후
- 한 번에 하나의 파일만 수정
- .claude/rules/coding.md 규칙 준수

### 3. 테스트
- 구현 완료 후 test-writer 에이전트로 테스트 작성
- 린트 실행: .claude/tools/check-lint.sh
- 엣지 케이스 직접 검토

### 4. 마무리
- 변경된 파일 목록 요약
- 커밋 메시지 제안
